# Bài Tập Vòng Lặp Kotlin

Dự án tổng hợp các bài tập cơ bản về vòng lặp (`for`, `while`) trong Kotlin.

## Nội dung bài tập (`BaiTapVongLap.kt`)
- **Bài 1:** In các số từ 1 đến 10.
- **Bài 2:** Tính tổng các số từ 1 đến 100.
- **Bài 3:** In các số chẵn trong khoảng từ 1 đến 20.

## Cách chạy
Chạy hàm `main()` trong file `BaiTapVongLap.kt` bằng IntelliJ IDEA, Android Studio hoặc Kotlin CLI.
